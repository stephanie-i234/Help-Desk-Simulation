# Help Desk Simulation Lab

## Overview

This project demonstrates common Level 1 and Level 2 IT support tasks performed in a Windows Active Directory environment.

The goal of this lab is to simulate real-world help desk ticket workflows including ticket intake, investigation, resolution, documentation, and closure.

## Skills Demonstrated

* Active Directory User Management
* Password Resets
* Account Unlocks
* User Provisioning
* Employee Offboarding
* Security Group Management
* Domain Administration
* Troubleshooting Methodology
* Ticket Documentation
* Technical Communication

## Environment

* Windows Server 2022
* Active Directory Domain Services
* VMware Workstation
* Windows Client VM
* GitHub Documentation
